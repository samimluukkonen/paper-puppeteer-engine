# Internal v1.1 readiness — v1.1.5

Assessment dates: 2026-10-23–24. This is a private authoring-tool assessment, not a public release. No npm publication, remote release, tag or deployment is part of this work.

## Verdict and gates

**Internally ready for v1.1 private authoring, with no known blocking bugs in the exercised workflows.** Unit integration checks cover shared preview ownership, independent authoring/history, package loading and actual SceneRunner sampling. Required checks, builds and packed-consumer verification pass. The full browser run exposed failures that were fixed and individually rerun; an additional 48-scenario final suite passes on both development and production. Human artist acceptance has not been performed.

## Completed features and artist workflow

The existing Advanced Pose Library, per-property curve foundation, visual Graph Editor, independent animation variations, manual Motion Diagnostics and selected non-destructive cleanup remain in the same editor/document architecture. No new subsystem, secondary evaluator or editor controller was introduced. New tutorials cover focused Bézier handle editing, diagnostics and cleanup; existing pose, graph and variation tours remain available.

Artist documentation: [complete advanced workflow and troubleshooting](advanced-animation-workflow.md), [Pose Library](pose-library.md), [Graph Editor](graph-editor.md), [variations](animation-editor.md#create-an-animation-variation), [diagnostics and safe cleanup](motion-diagnostics.md), [project/package workflow](artist-workflow.md) and [Feature Guide catalog](animation-editor-guides.md). The [profiling guide](profiling.md) includes reproducible local commands and workload limits.

The combined desktop workflow in `tests/browser/advancedAuthoring.spec.ts` passed against both development and production, including the final regression run: create a project, register the shipped character, create an empty clip, author and save a selected-bone pose, reapply it at another time, create additional keys, edit a Bézier curve/handles, play motion, preview/cancel and create a scaled variation, edit independently, analyze/preview/cancel/apply cleanup, Undo/Redo, refresh/recover poses and both clips, export/reimport JSON and use the variation in a Scene Editor action. Exported project dependencies are loaded and checked afterward. All three new guide navigation scenarios passed without changing authored snapshots.

## Integration findings and fixes

| Finding                                                                                     | Final behavior and evidence                                                                                                                                                                                                                   |
| ------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A library pose could retain a variation's temporary animation/clock underneath it           | Pose preview cancels variation preview before installing its pose. The actual Puppet returns to the authored clock; no authored edit or event is produced.                                                                                    |
| Starting playback could leave a library pose held over the animation                        | Playback invalidates the pose overlay before preview subscribers synchronize. Authored motion and event timing remain authoritative.                                                                                                          |
| Cleanup canvas and selected IK inspector could sample different times                       | IK inspector uses the same cleanup preview snapshot/time for Before and After. Cancel restores authored-clock sampling.                                                                                                                       |
| Pose Library bridge scanned every pose on every state notification                          | Immutable rig/library identity invalidates presentation; clock-only notifications perform no compatibility scans or React notifications. Existing compatibility checks still guard Preview/Apply.                                             |
| Linear diagnostics repeatedly sampled constant-speed segments and scalar subdivisions       | Constant-speed linear segments avoid redundant interval samples; linear scalar cleanup compares original knots, which bound continuous piecewise-linear error. Rotation retains subdivision checks; nonlinear speed uses the runtime sampler. |
| Refresh during an unfinished field/graph preview could skip the latest committed JSON draft | The JSON fallback flushes its immutable committed working snapshot even before the debounce elapses. Deterministic field and graph regressions recover that snapshot and verify Undo/Redo; previews remain excluded.                          |
| The shared desktop header extended eight pixels beyond a 1,000-pixel window                 | The existing shared header permits wrapping and shrinking within the desktop workspace. No page-specific header or mobile layout was added.                                                                                                   |

Browser regression maintenance also corrected outdated pose-category and static-WebP expectations, deployment-base navigation and retained-recovery handling. Canvas equality checks compare intrinsic rendered pixels after painting, so save-feedback rows changing the CSS preview size do not produce false pose differences. Drag fixtures initiate an actual drag before scrolling or panning the destination.

Graph Editor continues to use shared bone/IK selection, authored snapshots and the single preview evaluator. Variations own independent frozen curves, events and keyframe branches. Pose application, curve commits and cleanup each use normal animation history. Pose-library history is independent. Creating a variation creates a new document with an empty history; it is not an edit to undo on the source. Complete IndexedDB recovery restores authored documents, not live Undo/Redo histories.

## Compatibility and persistence

Animation and pose formats remain version 1; scene format remains version 2. No public engine API or schema changes were needed. Existing suites cover legacy linear clips, smooth/stepped playback, curves in layers/crossfades, shortest-path rotations, IK channels, baking/suppression, mirroring, onion skins and timed JSON events. New cross-tool coverage carries posed and curved variation data through cleanup, JSON replacement, character ZIP, CharacterLoader, project ZIP and SceneRunner seeks. Scene sampling checks both a curved root and independently authored values; owned Puppets are destroyed on reconstruction/disposal.

Temporary pose/variation/cleanup previews do not edit working snapshots, history or exports. Graph drag proposals remain validated transient snapshots; pending gestures block complete package capture. The JSON fallback can flush the last committed animation while a separate preview remains active. Legitimate commits use existing autosave/recovery. Browser refresh recovery and exported package checks are part of the combined workflow; local drafts still require successful storage before refresh.

## Remaining issues and v1.2 priorities

**Blocking bugs:** none known after the fixes and completed automated checks above. This verdict applies to the exercised private-tool workflows; it does not replace a human artist session.

**Usability limits:** diagnostics heuristics can flag intentional motion, comparisons show local rather than world-space error, dense manual analysis can pause the UI, and large expanded timelines/switching remain perceptible. Variations use their name as a stable ID. Character/project ZIPs remain the disk backup; complete local recovery restarts history. A human artist should practice the integrated workflow before relying on it for irreplaceable work.

**Deferred enhancements:** cross-rig pose retargeting/blending, IK target pose capture, Bézier overshoot/unbounded handles, IK group clipboard/marker dragging, world-space/contact-drift inference without contact intervals, and cleanup of nonlinear/stepped/large channels. These remain excluded from v1.1.

Recommended v1.2 priorities, subject to the two artists' actual needs: collect human workflow friction first; profile real production clips before choosing further performance work; consider stable-ID rename/reference tooling and deliberate artist-requested contact semantics. No new major subsystem is proposed by this hardening milestone.
