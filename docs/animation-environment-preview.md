# Animation Environment Preview

[All guides](../README.md#guides)

Open **Feature Guide → Animation → Environment Preview** for a ten-step tour of backgrounds, floor alignment, fixed/follow cameras, framing, synchronized playback, deterministic scrubbing and portable saving. The tour reveals panels without changing settings, images, playback or authored data. It is available with a valid character and a selected animation, including an empty clip; no background image is required.

Enable **Environment Preview** above the Animation Editor canvas. Open the initially collapsed **Environment Preview** inspector section to choose a background from the project image library or import a PNG/static WebP. **Load project character images** also offers existing character artwork. Select a background, enter its center X/Y and uniform scale, then choose **Apply background transform**. **Show background** hides artwork while retaining its selection and transform; **Clear background** releases the preview without deleting the shared asset.

The background uses animation preview-world pixels: positive X points right, positive Y points down, and position identifies the image center. The character's undisplaced preview origin is `(380, 435)`; background `(0, 0)` identifies the world origin. A scale of `1` uses the image's native pixel size. Wheel zoom, middle-button pan and editor resizing change the camera view while retaining these world coordinates.

Use the existing timeline's **Play/Pause**, **Restart**, speed, preview loop and scrub controls. The character pose, optional [preview displacement](motion-preview.md), ground contacts and camera all use that animation time. Pausing holds the entire preview. Restart returns to the configured beginning, retaining the current play/pause state. Each loop resets displacement to its configured first position, including nonzero starting offsets. Continuous travel over repeated cycles is unavailable; no position is accumulated from previous frames.

Open the initially collapsed **Preview Camera** section inside Environment Preview. **Fixed** holds the selected world center while the character travels. **Follow Character** adds the evaluated preview displacement to that center, so the static world artwork scrolls in the viewport. It follows the outer preview placement; authored bone/root motion continues inside the skeleton. **Camera X/Y** start at `(380, 435)` and **Zoom** at `1`; apply the form to set them. Zoom accepts `0.1–4`. Native middle-button pan and wheel zoom adjust the same preview camera, including a framing offset in Follow mode. Desktop resizing retains its world center. **Reset Camera** restores Fixed, `(380, 435)` and zoom `1`. Character movement is never clamped to background edges; zoom out, reset or follow to inspect travel beyond the image.

Disabling Environment Preview or entering Rig/Rig Tweak restores the previous ordinary editor camera exactly. Reenabling returns to the configured environment camera without changing animation time, pose or displacement settings. Camera controls do not edit scene cameras, character transforms, animation keys, authored history or production exports. Reset Environment also resets the preview camera. The existing ground guide and optional foot markers remain world references evaluated from the final pose and displaced Puppet; passive viewing never snaps feet, changes IK or corrects drift.

**Show Ground Reference** controls the existing guide, also available in **Ground reference**. **Align image bottom to ground** sets background center Y to `ground Y − image height × scale / 2`, preserving X and scale. For a visible floor inside an image, adjust Background Y until that floor meets the guide. Background alignment never changes bones, IK targets or keys. **Reset background transform** restores `(0, 0)` and scale `1`; **Reset Environment** clears the selection and disables Environment Preview while keeping shared assets and ground settings.

Environment preferences are stored once per character in optional project `editorPreferences.animationPreview[characterId]` metadata. Background selection, enabled/visible state, transform, ground and default camera are shared across clips. Each animation retains its own displacement enabled state, points, interpolation, trajectory visibility and **Loop preview** flag. Every loop resets displacement; continuous travel remains unavailable. Preview preferences have no animation Undo entries; Ground reference retains its separate preference history.

Wait for **Local draft saved** before refreshing. Recover the draft through **Recover Draft**; standalone recovery opens a complete project in Project Workspace. Export a **project ZIP** to keep preferences and background artwork on disk, then import it to reopen. Character/animation JSON and character ZIPs contain production data only and exclude preview preferences and standalone background binaries. Clearing/resetting preview configuration preserves the shared image library. Scene Editor cleanup protects active preview references; its explicit unused-image cleanup can remove artwork after all references are cleared. A missing optional background preserves the character and its animation: select or import a replacement in Background. Missing scene artwork still follows the existing scene dependency validation.

See the [v1.1.6.4 integration report](animation-environment-readiness.md) for architecture, verification and limitations.

React's `EnvironmentPreviewController` owns immutable typed settings, image discovery/import requests and feedback. `EnvironmentPreviewPanel` uses the existing inspector controls; both checkboxes subscribe to that same owner. The project bridge supplies the project's existing `SceneImageRegistry`, while standalone editing uses a session registry. No Blob URL becomes an asset reference.

`AnimationEditorScene` owns an `EnvironmentPreviewLayer` adapter over the existing `SceneImageLayer`. It creates a world image at background depth with scroll factor `1`, using the same camera as the character. The layer stays inactive in Rig Editor/Rig Tweak and releases images/textures on hiding, clearing, disabling or shutdown. Image decoding, byte/pixel guards, cancellation and temporary URL cleanup reuse the scene renderer. Missing assets report a recoverable error and retry when registered. The authoritative Puppet, evaluator, IK, attachments, skins, facing and playback remain under their existing owners.

`AnimationEditorPlayback` remains the sole continuous clock. `EnvironmentPreviewCamera` subscribes to editor, motion and environment changes and evaluates the same `previewTimeMilliseconds` through `motionPreviewSampleTime` as the pose/displacement adapter. Held stepped frames and exact endpoints therefore agree. `previewCamera.ts` holds typed immutable camera settings and pure fixed/follow center evaluation. The adapter applies Phaser `setZoom`/`centerOn` directly, saves ordinary navigation once on entry and restores it on exit/disposal. It captures native navigation before advancing playback and reapplies the configured center after resizing. It starts after initial character fitting and releases every subscription on shutdown or failed setup. The existing cinematic camera utilities author/evaluate scene cameras and are not needed for this editor viewport.

A seek computes pose, displacement and camera from authored data and preview configuration rather than the previous frame. Background transforms and ground Y never depend on animation time or camera mode. The detached pose player samples without events, and direct editor navigation does not dispatch gameplay callbacks, cues or audio. Real playback retains its existing post-pose event notifications. No Actor movement promise, separate player clock or asynchronous movement starts during seeks.

Regression coverage lives in `environmentPreview.test.ts`, `sceneImageLayer.test.ts`, `animationEditorScene.test.ts` and the local-only `animationEnvironmentPreview.spec.ts` desktop browser workflow. It checks settings, import/deduplication/cancellation, world placement, ground alignment, missing-image recovery, character continuity, multiple animations, unchanged authored packages, texture cleanup and browser zoom/pan/resizing.

## Implementation files

- `src/devtools/shared/environmentPreview.ts`: reusable session-settings type, validation and renderer adapter.
- `src/devtools/animation-editor/EnvironmentPreviewController.ts`, `EnvironmentPreviewPanel.tsx` and `EnvironmentPreviewLayer.ts`: request/settings ownership, React controls and existing Phaser image-layer integration.
- `src/devtools/animation-editor/EnvironmentPreviewCamera.ts`, `previewCamera.ts`: deterministic preview camera evaluation, native navigation, viewport restoration and subscription cleanup.
- `src/devtools/animation-editor/AnimationEditorScene.ts`, `main.tsx`, `editorMarkup.tsx` and `style.css`: workspace wiring, mode/shutdown lifetime and compact inspector layout.
- `src/devtools/project/projectBridge.ts` and `ProjectEditorHosts.ts`: share the existing project image registry with character editors.
- `tests/environmentPreview.test.ts`, `tests/sceneImageLayer.test.ts`, `tests/animationEditorScene.test.ts` and `tests/browser/animationEnvironmentPreview.spec.ts`: unit/integration and local desktop regressions.
- `tests/environmentPreviewCamera.test.ts`, `tests/browser/animationMotionPreview.spec.ts`: fixed/follow/zoom, pose and foot-contact synchronization, play/pause/restart/speed, silent arbitrary seeks, loop reset, facing/IK, lifecycle and unchanged authored exports for a sword cut, jump and walk.
- `src/devtools/shared/guides/anchors.ts` and `animationGuides.ts`, plus `tests/animationGuides.test.ts`, `guideRegistry.test.ts` and `tests/browser/animationEnvironmentGuide.spec.ts`: the ten-step Explain guide and target/prerequisite/state-preservation regressions.
- `AGENTS.md`, `CHANGELOG.md`, `README.md` and this guide: version policy, milestone `1.1.6-1` changelog and documentation. The existing higher package version `1.2.6` is preserved, with matching lockfile metadata.
